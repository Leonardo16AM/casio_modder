# Casio Modder

Design custom LCD backgrounds for the **Casio F-91W** and **A158 / A168**, preview them with live LCD digits, and export a **real-size PDF** to print, cut and install.

**Live site:** https://leonardo16am.github.io/casio_modder/

- A4 / Letter / A5 / A3 / Legal sheets, portrait or landscape
- Grid of real-size cells (F-91W 21 × 11 mm, A158/A168 ≈ 23.5 × 12.5 mm, or custom)
- Photo (zoom, pan, rotate, flip, brightness/contrast/saturation), gradient or solid fill per cell
- Live 7-segment digit overlay to check readability
- PDF in millimetres with cut lines, crop marks and a 50 mm calibration ruler — print at **100% / Actual size**

The A158/A168 size is an estimate — measure your LCD with calipers and use the Custom size.
